# Mplayer 배포

- **내려받기 페이지** (열면 최신 버전을 바로 내려받음): https://fotiblabs.github.io/mp3_player_app-releases/
- 최신 파일 직접 링크 (파일 이름 `Mplayer.apk`): https://github.com/FOTIBlabs/mp3_player_app-releases/releases/latest/download/Mplayer.apk

설치 파일은 비공개 코드 저장소의 GitHub Actions가 자동으로 올립니다. 각 릴리스에는 버전이 붙은 `Mplayer<버전>.apk`와 같은 내용의 `Mplayer.apk`가 함께 있습니다.
